# Pronto Resolver Integration

## System Overview

Pronto Resolver is Future Energy's ticket management system. Tech stack: React 18 + TypeScript + Vite frontend, Supabase (PostgreSQL + Auth + RLS) backend, Firebase Storage for files, Salesforce CRM integration.

Modules: Tickets, Technical Visits, Drones, Tasks, Reminders, Announcements, Cafeteria, Notifications.

## Authentication

Supabase Auth with JWT. All API calls need these headers:

```
Authorization: Bearer <access_token>
apikey: <SUPABASE_ANON_KEY>
Content-Type: application/json
```

### Sign In

```bash
POST https://rczhnuurvcxtkfussmfj.supabase.co/auth/v1/token?grant_type=password
# Body: { "email": "...", "password": "..." }
# Returns: { "access_token": "...", "refresh_token": "...", "expires_in": 3600 }
```

### Refresh Token

```bash
POST https://rczhnuurvcxtkfussmfj.supabase.co/auth/v1/token?grant_type=refresh_token
# Body: { "refresh_token": "..." }
```

### Roles

| Role | Access |
|------|--------|
| `admin` | Full access, user management, delete tickets |
| `technician` | Manage tickets, delete tickets |
| `user` | Create/view tickets |
| `proveedor_externo` | External provider, limited access |

Check role via RPC: `POST /rest/v1/rpc/has_role` with `{ "user_id": "...", "role": "admin" }`.

## Supabase REST API

Base: `https://rczhnuurvcxtkfussmfj.supabase.co/rest/v1`

### Tickets

```bash
# List (paginated, filtered)
GET /tickets?select=*&order=fecha_creacion.desc&limit=50&offset=0
GET /tickets?estado=eq.abierto&prioridad=eq.alta

# Get by folio
GET /tickets?folio=eq.TKT-00001&select=*

# Create (folio auto-generated by DB trigger)
POST /tickets
{
  "area": "Soporte Tecnico",
  "responsable": "John Doe",
  "responsables": ["John Doe", "Jane Smith"],
  "responsables_ids": ["uuid-1", "uuid-2"],
  "prioridad": "alta",
  "sla_minutos": 480,
  "estado": "abierto",
  "canal": "email",
  "asunto": "Subject",
  "descripcion": "Description",
  "cliente_nombre": "Client",
  "cliente_contacto": "contact@client.com"
}

# Update
PATCH /tickets?id=eq.<uuid>
{ "estado": "en_progreso" }

# Delete (admin/technician only)
DELETE /tickets?id=eq.<uuid>
```

#### Ticket Fields

| Field | Type | Values |
|-------|------|--------|
| `id` | UUID | auto |
| `folio` | string | auto (TKT-00001) |
| `fecha_creacion` | timestamp | auto |
| `fecha_ultima_actualizacion` | timestamp | auto |
| `fecha_vencimiento` | timestamp | computed SLA deadline |
| `area` | string | free text |
| `responsable` | string | primary assignee name |
| `responsables` | string[] | all assignee names |
| `responsables_ids` | UUID[] | all assignee user IDs |
| `prioridad` | enum | `alta`, `media`, `baja` |
| `sla_minutos` | int | business minutes |
| `estado` | enum | `abierto`, `en_progreso`, `resuelto`, `escalado` |
| `canal` | enum | `whatsapp`, `email`, `telefono`, `presencial`, `reporte` |
| `asunto` | string | subject |
| `descripcion` | text | description |
| `notas_internas` | text | internal notes |
| `cliente_nombre` | string | client name |
| `cliente_contacto` | string | client contact |
| `created_by` | UUID | creator user ID |

## Edge Functions

Base: `https://rczhnuurvcxtkfussmfj.supabase.co/functions/v1`

### `POST /functions/v1/check-reminders`

Processes due reminders, sends push notifications. Normally triggered by pg_cron every 5 min.
Auth: service-role key. Response: `{ "processed": 3 }`.

### `POST /functions/v1/create-proveedor-externo`

Creates external provider user. **Admin only**.

```json
// Request body:
{ "email": "...", "password": "...", "first_name": "...", "last_name": "...", "company": "..." }
// Response:
{ "success": true, "user_id": "uuid", "email": "...", "message": "..." }
```

Errors: 401 (no auth), 403 (not admin), 400 (validation).

### `POST /functions/v1/firebase-token`

Generates Firebase custom token for Storage access. Auth: user JWT.
Response: `{ "token": "..." }`.

## Realtime Subscriptions

```typescript
import { createClient } from '@supabase/supabase-js';
const supabase = createClient(SUPABASE_URL, ANON_KEY);

// Subscribe to ticket changes
supabase.channel('tickets')
  .on('postgres_changes', { event: '*', schema: 'public', table: 'tickets' },
    (payload) => console.log(payload))
  .subscribe();

// Subscribe to user notifications
supabase.channel('my-notifs')
  .on('postgres_changes', {
    event: 'INSERT', schema: 'public', table: 'notifications',
    filter: `user_id=eq.${userId}`
  }, (payload) => console.log(payload))
  .subscribe();
```

Realtime-enabled tables: `tickets`, `notifications`, `reminders`, `announcements`, `drones`, `drone_sessions`, `cantina_resources`.

## Error Handling

| HTTP Status | Meaning |
|-------------|---------|
| 400 | Bad request / validation |
| 401 | Invalid or expired JWT |
| 403 | RLS policy denied (insufficient permissions) |
| 404 | Not found |
| 409 | Conflict (duplicate) |
| 422 | Unprocessable entity |
| 500 | Server error |

Supabase errors: `{ "code": "PGRST...", "message": "..." }`.
Edge function errors: `{ "error": "..." }`.
Salesforce errors: `{ "salesforceErrors": [{ "message": "...", "errorCode": "...", "fields": [...] }] }`.

## Best Practices

1. Always send both `apikey` and `Authorization` headers for Supabase
2. Refresh tokens before expiry (1h default)
3. Use `select=field1,field2` to minimize payload
4. Implement webhook idempotency via `timestamp` + `event` + resource ID
5. Use realtime subscriptions instead of polling
6. Paginate with `limit` and `offset`
7. Cache Salesforce responses (opportunity data changes infrequently)
8. Handle 403 gracefully -- means RLS denied the operation

## Client Library Quick Start

### JavaScript/TypeScript

```typescript
import { createClient } from '@supabase/supabase-js';

const supabase = createClient(
  'https://rczhnuurvcxtkfussmfj.supabase.co',
  'YOUR_ANON_KEY'
);

await supabase.auth.signInWithPassword({ email: '...', password: '...' });

const { data: tickets } = await supabase
  .from('tickets')
  .select('id, folio, asunto, estado, prioridad')
  .eq('estado', 'abierto')
  .order('fecha_creacion', { ascending: false });
```

### Python

```python
from supabase import create_client

supabase = create_client("https://rczhnuurvcxtkfussmfj.supabase.co", "YOUR_ANON_KEY")
supabase.auth.sign_in_with_password({"email": "...", "password": "..."})

tickets = supabase.table("tickets") \
    .select("id, folio, asunto, estado, prioridad") \
    .eq("estado", "abierto") \
    .order("fecha_creacion", desc=True) \
    .execute()
```

Available libraries: `@supabase/supabase-js` (JS), `supabase-py` (Python), `supabase_flutter` (Dart), `supabase-swift`, `supabase-kt` (Kotlin), `supabase-csharp` (C#).
